# Фича `home`

**Владелец:** модуль A (лид)

## Что делает
Главный экран сверху вниз: приветствие по имени (первое слово `profiles.full_name`) и дата → карточка
«Bugungi salomatlik indeksi» → сетка «Xizmatlar» 3×3 на все экраны фич → «Siz uchun» — карточки всех фич из
`homeCardsProvider` (собираются в `feature_registry.dart`, сортировка по `order`; пустой список — секция скрыта).

**Индекс Sino 0–100** (`application/sino_index.dart`, за день, без диагноза): питание 25 (ккал к цели — Миффлин–Сан Жеор
из профиля ×1.375, как у nutrition; до 110 % цели — полный балл, 150 % — ноль), вода 20 (стаканы / 8), лекарства 20
(принято / наступившие дозы своих `reminders`, без членов семьи и на паузе), активность 20 (тренировка = полный балл,
иначе шаги `vitals.steps` / 8000), сон 15 (`vitals.sleep`, 7–9 ч = полный). Сегодня цели берутся пропорционально
прошедшей части дня (7:00 → 21:00, минимум 25 %). **Часть без данных не учитывается** — веса остальных растягиваются
до 100; совсем нет данных → `null`. Данные: `data/sino_data.dart` — `SinoDataRepository` читает таблицы напрямую
(только select своих строк, код коллег не импортируется); Fake — неделя «Aziz» из `assets/core/sino_week.json`
(один слабый день, сегодня 1 240 ккал и 5 стаканов). Провайдеры: `sinoWeekProvider` (7 дней, сегодня последний),
`sinoTodayProvider`, `sinoClockProvider` (подменяется в тестах).

Индекс v1 (`application/health_index.dart`, только из анкеты): ИМТ 40 (норма 18.5–24.9 → 40, −4 за единицу вне
нормы, мин. 8) + возраст 20 (до 30 → 20, −0.4/год, мин. 6) + медданные 20 (группа крови указана) + активность 20
(v1: нейтрально 10). Максимум v1 — 90. Тап → разбивка и советы с переходом в фичи. Дисклеймер на карточке.
