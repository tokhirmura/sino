# Фича `sos`

**Владелец:** модуль A (лид)

## Что делает
Экран `/sos` сверху вниз:
- **Кнопка SOS:** удерживать 2 с (раньше отпустил — сброс). Затем геопозиция (`LocationRepository`: geolocator,
  в fake — Ташкент) и «отправка» семье из `familyMembersProvider` — **мок**, наружу ничего не уходит. В карточке
  результата: кому, координаты, «SMS yuborish» (`sms:` с текстом: ссылка на карту, группа крови, аллергии) и 103.
- **Быстрый звонок** 103 / 101 / 102 / 104: `tel:` открывает набор номера, сам не звонит. Нет звонилки — подсказка.
- **Shifokorlar uchun:** имя, возраст, группа крови, аллергии из `profiles`.
- **Первая помощь офлайн:** 6 инструкций из `assets/core/first_aid.json` (реанимация, удушье, кровотечение, ожог,
  инсульт, тепловой удар) — `{uz, ru, en}`, шаги по языкам; экран инструкции с кнопкой 103. Таблицы в БД нет:
  контент встроен в приложение и работает без интернета в обоих режимах.
- Внешние ссылки открываются через `externalLauncherProvider` (в тестах подменяется).
